# ARLOTECH Outreach Intelligence - Application-wide UI update

This update applies a consistent visual system across the existing application without changing business logic, database schemas, API behavior, authentication, or prospect/audit data.

## Scope

The shared styling layer covers the authenticated workspace and its existing sections:

- Dashboard and Activity
- Prospects, New Prospect, and Prospect Details
- Website Intelligence and audit results
- Campaigns and Email Drafts
- Replies and Follow-ups
- Analytics and Growth Center
- Settings

## What changed

- Unified workspace colors, typography, spacing, borders, radii, and shadows.
- Refined the sidebar, navigation states, brand area, and footer panel.
- Improved top-bar sizing and responsive behavior.
- Standardized page-title hierarchy, cards, metric tiles, and panels.
- Improved button, input, select, textarea, table, tab, and dialog styling.
- Added responsive adjustments and reduced-motion-aware transitions.
- Preserved the existing BLACKSITE theme while polishing its spacing and controls.
