# Mobile Navigation Update

## What changed

- Added a fixed five-destination mobile navigation bar: Home, Prospects, Audits, Outreach, and More.
- Added a scrollable More directory for Activity, Campaigns, Replies, Follow-ups, Website Intelligence, Analytics, Growth Center, and Settings.
- Added active-route styling, accessible dialog behavior, keyboard dismissal, focus handling, backdrop dismissal, and close-on-navigation behavior.
- Added mobile safe-area spacing, reduced-motion support, and BLACKSITE theme styling.
- Integrated the archive's workspace visual-system styles while preserving the current app's later fixes and mobile-specific overrides.
- Kept the desktop sidebar and existing routes.

The mobile navigation is visible below 768px. The ZIP is a project snapshot; files already identical to the project did not need changes. Later fixes in the current project were preserved rather than replaced by older archive copies.
